# Android 기기 검증

현재 작업 컴퓨터의 `adb devices`에는 연결된 Android 기기가 없었다. 아래 검증은 실제 기기에서 수행해야 한다.

1. GitHub Actions의 `vpngate-android-debug-apk` 또는 로컬 `main-ui-ovpn23-universal-debug.apk`를 설치한다. 기존 OpenVPN for Android와 별도 앱으로 표시되는지 확인한다.
2. VPN Gate 탭에서 서버 목록 갱신 시각, 국가 필터, 핑·속도·세션·기록 정책을 확인한다. 한국 서버가 기본 목록에서 숨겨지고 `All countries`에서 보이는지 확인한다.
3. 해외 서버를 선택해 기록 정책 안내를 확인한다. `Read policy` 링크와 취소 동작을 시험하고, 다시 선택해 Android VPN 동의를 완료한다.
4. 연결 후 기기의 VPN 표시와 외부 IP가 선택한 서버의 국가로 바뀌었는지 확인한다. DNS 조회와 IPv6 트래픽이 의도치 않게 원래 네트워크로 빠져나가지 않는지 확인한다.
5. 앱의 `Disconnect VPN`으로 연결을 종료하고 외부 IP가 원래대로 돌아오는지 확인한다.
6. Wi-Fi와 모바일 데이터를 전환하고, 화면 잠금·해제 후 연결 상태와 재연결을 확인한다.
7. 인터넷을 끊은 상태로 목록을 새로 고쳐 캐시 시각이 표시되는지 확인한다. 더 이상 운영하지 않는 서버나 연결 거부 서버에서는 앱이 실패를 알리고 다른 서버에 자동 연결하지 않는지 확인한다.
